# Employee Retention Predictor

Employee Retention Predictor using Machine Learning and Streamlit

---

## 📌 Project Overview
The Employee Retention Predictor is a Machine Learning-based web application developed using Streamlit. It predicts whether an employee is likely to stay in the organization or leave based on employee-related information.

This project helps HR departments identify employees at risk of attrition and supports better decision-making.

---

## 🚀 Features
* Predicts employee retention using Machine Learning
* User-friendly Streamlit web interface
* Displays employee risk level
* Shows prediction confidence score
* Provides HR recommendations

---

## 🛠️ Technologies Used
* Python
* Streamlit
* Pandas
* Scikit-learn
* Joblib
